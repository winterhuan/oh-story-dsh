# Agent Note: 同步上游 0.1.28 并保留 fork 的宿主与安装约定

Status: implemented

## Problem

上游 `zenstory-ai/oh-story-dsh` 的 `v0.1.28` 更新三套创作技能和工作台，并默认使用 DSH `0.2.2-rc.5`。本 fork 的日常安装使用固定源码 Tag，宿主及其他插件仍固定为 `0.2.2-rc.1`；上游包名、浏览器入口和空工作区行为也不同。

## Decision

`0.1.32` 合并上游 `eedf5dc9179f5e5a69dffecd19643f890ed5f977`，保留 `@winterhuan/oh-story-dsh`、官方 Ego 接入、空工作区默认展开和源码 Tag 安装。开发依赖、覆盖规则及默认打包验证仍使用 DSH `0.2.2-rc.1`，兼容验证覆盖 `0.2.0-rc.2` 与 `0.2.2-rc.5`。

新版 Hero 插槽仍由支持它的宿主声明和挂载。注册经绑定的公开 slots 方法延迟执行，使旧版类型和运行时可以保留原生回退路径，无需伪造旧 SlotMap 中不存在的 HOC 类型。空工作区的可用性与实际创作项目识别分别保留。

## Alternatives considered

- 直接替换成上游包：改变既有包名、浏览器与空工作区约定。
- 同步升级全部 DSH 插件与宿主：超出这次单插件更新范围。
- 日常服务改成本地链接：破坏固定远程安装的约定。

默认宿主的整套升级由[rc.5 对齐记录](2026-11-25-align-default-host-with-dsh-rc5.md)覆盖；本记录继续约束 fork 包名、安装来源、浏览器和工作区行为。

## Consequences

小说、短剧、视频技能分别更新到 `0.11.0`、`0.13.0`、`0.8.0`，游戏保持 `0.9.0`。小说上游保留 14 个技能供完整性校验，fork 对外提供 13 个；角色和研究流程继续使用官方 Ego。Video Recap 0.7 项目保留读取兼容，继续旧单体流水线需要固定到 fork `0.1.31`。这次更新不迁移作品文件或其他日常 profile。
